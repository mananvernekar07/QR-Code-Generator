# 📱 QR Code Generator

A simple, fast, and free **QR Code Generator** built with Python.

This project allows users to enter text or a URL and instantly generate a QR code through a simple web interface.

## ✨ Features

- 🔗 Generate QR codes from text or URLs
- ⚡ Simple and fast web interface
- 🖥️ Browser-based application
- 🐍 Built with Python
- 📥 Generated QR codes are displayed directly in the application
- 🎨 Clean and beginner-friendly implementation

## 🛠️ Technologies Used

- 🐍 Python
- 🌐 Flask
- 📦 qrcode
- 🖼️ Pillow
- 🚀 Gunicorn
